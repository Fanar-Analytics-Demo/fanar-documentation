# Welcome to Fanar

Fanar helps your team connect to data sources, write queries, build dashboards, and share insights. It is based on [Redash](https://github.com/getredash/redash), with additional capabilities such as an AI agent and copilot for natural-language querying and dashboard creation.

## Quick links

- [Getting started](./user-guide/getting-started) — first steps in the UI
- [Setting up Fanar](./self-hosted/setup) — install and configure a self-hosted instance
- [Development guide](./self-hosted/dev-guide) — contribute to the Fanar application
- [AI agent](./fanar/agent) — natural language to SQL and dashboards
- [Multi-org deployment](./fanar/multi-org) — run multiple organizations on one instance
